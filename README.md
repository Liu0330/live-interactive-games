# 直播互动玩法控制台

给抖音主播用的**本机互动玩法台**：开一个竖屏游戏画面，用「抖音直播伴侣」窗口采集推到直播间，观众发弹幕就能玩。

同一套壳里有 6 个玩法，控制台随时切换，不用重启：

1. **语义猜词**（主玩法，画面标题「挑战最强大脑」）
2. **弹幕答题**
3. **数字炸弹**
4. **弹幕抽奖**
5. **成语接龙**
6. **看图猜**（表情猜成语或歌名）

本仓库是原创实现，不包含任何商业软件的安装包、卡密或破解。

---

## 环境要求

- Windows / macOS / Linux
- Python 3.11 或以上
- Google Chrome（或 Edge）用来打开控制台和游戏画面
- 推荐：MiniMax API Key（对话、语义向量、礼物和进场语音）
- 可选：OpenAI 兼容的对话接口，MiniMax 未配置时用来扩词和相关词预取
- 可选：硅基流动 API Key，MiniMax 未配置时用来做语义向量和 CosyVoice 语音

## 安装

在项目目录打开终端：

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

Windows 没有系统时区数据。上面这条会装上 `tzdata`。没装的话，`app/db.py` 里的 `ZoneInfo("Asia/Shanghai")` 会抛 `ZoneInfoNotFoundError`，服务起不来。虚拟环境已经建过的话，激活后再执行一次 `pip install -r requirements.txt`。

```bash

```

浏览器打开：

| 页面 | 地址 |
| --- | --- |

## 第一次开播流程（抖音直播伴侣）

1. 本机先 `python -m app`，确认控制台和 Overlay 都能打开。
2. 打开 **抖音直播伴侣**，登录你自己的账号。
3. 在伴侣里选 **添加窗口**（或「窗口采集」），选中 Chrome 里的 **游戏画面** 那个窗口。
4. 把采集区域裁成 **竖屏 9:16**。推荐画布 **1080 × 1920**。
5. 直播分类选 **其他游戏玩法**（按平台当前类目为准，不要乱选违规类目）。
6. 无人值守或不说话时，把麦克风静音，避免环境噪音。
7. 背景音乐可用汽水音乐等本机播放器，音量压低，不要盖过游戏提示音。
8. 控制台先用「模拟弹幕」走一遍：开启新回合 → 发几个词 → 看 Overlay 排名是否跳动。
9. 确认无误后再点「开始直播」。

Overlay 按 1080×1920 设计，窗口随便缩放都会等比适配。伴侣里把黑边裁掉即可。

## MiniMax（推荐）

国内 MiniMax 一套密钥就能做三件事：对话扩词、语义向量计分、礼物和进场的语音感谢。在控制台「MiniMax」里填写，或在主播电脑上设置环境变量。下面全是占位值，把密钥换成你自己的：

```bash
MINIMAX_API_KEY=sk-replace-me
MINIMAX_BASE_URL=https://api.minimaxi.com
MINIMAX_CHAT_MODEL=MiniMax-M3
MINIMAX_EMBED_MODEL=embo-01
MINIMAX_TTS_MODEL=speech-02-turbo
MINIMAX_TTS_VOICE=male-qn-qingse
```

只设 `MINIMAX_API_KEY` 也可以，其余会用上面的默认值。同一份配置写在本机 `data/config.json`（已在 `.gitignore` 里，不要提交），字段名是：

```json
{
  "minimax_api_key": "sk-replace-me",
  "minimax_base_url": "https://api.minimaxi.com",
  "minimax_chat_model": "MiniMax-M3",
  "minimax_embed_model": "embo-01",
  "minimax_tts_model": "speech-02-turbo",
  "minimax_tts_voice": "male-qn-qingse"
}
```

环境变量非空时盖过这个文件。控制台里密钥留空再点保存，不会清掉已经保存的密钥。

配好之后：

1. **AI 生成并入库**、**生成题目** 走 MiniMax 的 Anthropic 兼容对话接口（`/anthropic/v1/messages`）。如果回复里夹了 `<think>` 标签，会先剥掉再解析。
2. 语义猜词用 `embo-01` 向量。谜底按 `type=db` 缓存，观众的词按 `type=query` 缓存，都写在本机 SQLite。弹幕进来只查缓存，**不会等网络**。缓存没有时先用本地拼音+字面，向量回来后再更新分数。
3. 猜中分取本地分和向量分里的较高者。默认向量分封顶在猜中阈值之下，同义词不会单靠模型分获胜。勾选「模型分可直接猜中」后才允许过线。谐音如果本地分已经够高，仍按本地规则判。
4. 向量超时、报错时继续用本地分。请求会合并成小批量，超时大约 8 秒。
5. 礼物感谢和进场欢迎用 `speech-02-turbo`。音色在控制台改，默认 `male-qn-qingse`。语音失败就改用浏览器 `speechSynthesis`。
6. 控制台「计分方式」显示「MiniMax 向量」，并写上当前语音来源。

好几个密钥同时存在时，计分和语音都优先 MiniMax，然后是硅基流动，再然后是下面的通用对话接口，最后是本地拼音和浏览器语音。

## 对话模型（可选）

没有 MiniMax 时，语义猜词、扩词库和出题可以走任意 OpenAI 兼容的 `chat/completions`。这个接口**只有对话**，没有向量，也没有语音。

在控制台「对话模型」里填写，或在启动前设置环境变量（下面是占位值，请换成你自己的）：

```bash
LLM_BASE_URL=https://codingplan.alayanew.com/v1
LLM_API_KEY=sk-replace-me
LLM_MODEL=glm-5.2
```

对应的 `data/config.json` 字段是 `llm_base_url`、`llm_api_key`、`llm_model`。默认模型 `glm-5.2`。留空密钥表示不用。

配好、且没有 MiniMax 时：

1. **AI 生成并入库**、**生成题目** 走这个对话接口。OpenAI 兼容回复里的 `<think>` 段会被剥掉。
2. 回合开始时后台要一份相关词和 0–100 的相关分，写入 SQLite。弹幕只查缓存。
3. 默认相关分封顶在猜中阈值之下。勾选「模型分可直接猜中」后才允许过线。
4. 超时或返回的不是 JSON 时，继续用本地拼音+字面。
5. 控制台「计分方式」显示「大模型相关词」。语音用浏览器 `speechSynthesis`。

如果同时还配了硅基流动、但没有 MiniMax，计分显示「硅基流动向量」，这个对话接口仍负责扩词和出题。

## 硅基流动（可选）

向量相似度和 CosyVoice 语音是附加能力，不配也能开播。

1. 打开 https://cloud.siliconflow.cn 注册并创建 API Key。
2. 在控制台「硅基流动」里粘贴密钥，选一个当前列表里的模型（默认 `deepseek-ai/DeepSeek-V3`）。
3. 点 **保存密钥**，再点 **测试连接**。
4. MiniMax 和上方的对话接口都没配时，扩词库走硅基流动。需要扩词库时填主题（如「食物」「四字成语」），点 **AI 生成并入库**。
5. 有密钥、且没有 MiniMax 时，语义相似度走 `BAAI/bge-m3` 向量，并与本地拼音/字面取较高值。
6. 语音播报：没有 MiniMax 时，有硅基流动密钥就走 CosyVoice；否则 Overlay 用浏览器 `speechSynthesis`。

**不要**把任何密钥写进仓库，也不要发给别人。文档和示例里只用 `sk-replace-me` 这种占位符。

## 观众怎么玩

观众在你的直播间发评论即可，无需安装任何东西。

| 玩法 | 怎么参与 | 怎么赢 |
| --- | --- | --- |
| 语义猜词 | 发一个词语 | 相似度达到阈值（默认 80%）或猜中谜底 |
| 弹幕答题 | 发 A/B/C/D 或完整答案 | 第一名正确得分 |
| 数字炸弹 | 发整数 | 猜中范围内的秘密数字（可改成「最后安全者赢」） |
| 弹幕抽奖 | 发口令（默认「抽奖」） | 倒计时结束滚动开奖，礼物可加权 |
| 成语接龙 | 发四字成语，接上一句的末字 | 接上就得分，同一局不能重复 |
| 看图猜 | 看表情，发成语或歌名 | 第一名猜中得分 |

控制台可以随时 **模拟弹幕 / 礼物档位 / 点赞连击 / 进场**，方便没开播时联调。

## 抖音房间直连（读你自己的直播间）

控制台填 `live.douyin.com/<房间号>` 后面的数字，点 **开始直连**。

程序会尝试用公开网页直播接口拉取你房间的弹幕和礼物，接到同一条评论总线。这是给你**自己的房间**用的，不要去连别人的房间做采集骚扰。

抖音网页协议经常改，直连失败时控制台会显示状态。此时：

1. 确认房间号正确、直播已经开出去；
2. 仍失败就用「模拟弹幕」或让场控在控制台代发；
3. 也可以自己写一个接入插件（见 `app/ingest/`），接到 `EventBus` 即可。

本程序**不会**用嵌入式浏览器去登录别人的账号，也没有卡密系统。

## 语义猜词说明

- 内置谜底在 `app/data/wordpool.txt`，第一行固定为 `# 语义猜词 谜底词库`，后面一行一词。控制台新增的词写进 `data/leaderboard.db`，和这个文件一起用。
- Overlay **不会提前显示谜底**。猜中或时间到才揭晓。
- 控制台实时状态类似：`当前回合正在 playing - 词语是 [ 巧夺天工 ]`。
- 礼物和点赞在六个玩法里都会接。规则在控制台「礼物档位」「点赞进度条」里改，写到本机 `data/config.json`。
- **禁止**往词库里加违规词、政治敏感、色情低俗内容。词库出事可能导致直播间被限流或 **10 分钟封禁**。

自带 200+ 条常见安全名词。控制台「题库」可以单条添加、一行一条批量粘贴、搜索、修改、删除、导入导出 TXT/CSV。配好 MiniMax 后按分类和主题生成，默认先预览再入库，也可以勾选直接入库。观众发 `出题 春卷` 或 `出题 #食物 面条` 会进待审核，通过后下一局才能抽到，当前这一局不会被换掉。弹幕答题、成语接龙、看图猜也在同一张卡片里。含政治、色情、赌博、毒品等明显不适合直播的内容会被拒绝。

## 礼物触发效果

礼物按档位生效，控制台可以改礼物名、钻石阈值和效果：

| 档位 | 默认礼物 | 默认效果 |
| --- | --- | --- |
| 小礼物（钻石 ≤ 9，或名称命中） | 小心心、玫瑰、大啤酒、人气票 | 当前回合解锁一条提示 |
| 大礼物（钻石 ≥ 10，或名称命中） | 鲜花、你最好看、嘉年华、跑车 | 加时 30 秒 |

大礼物还可以改成 **跳过当前** 或 **刷新题目/词语**。名称优先于钻石数。没对上名字、也没有钻石数的礼物，按小礼物处理，保证每个礼物都有反应。

每个礼物都会在 Overlay 上弹出感谢动画（送礼人 + 效果），进场也会播一句欢迎。有 MiniMax 密钥时用 MiniMax 语音，否则有硅基流动密钥时用 CosyVoice，都没有时用浏览器 `speechSynthesis`。

各玩法里的效果：

- 语义猜词：提示一个相关词；刷新会换一个新词，不在公屏上写出谜底
- 弹幕答题：提示会划掉一个错误选项；刷新会换题
- 数字炸弹：提示把范围砍半，但不会只剩一个数
- 弹幕抽奖：礼物提高中奖权重；大礼物若设为「跳过」会立即开奖，设为「刷新」会清空名单并重新计时
- 成语接龙：小礼物逐步揭开一个能接上的成语（不会一次给全）；跳过或刷新会换一个新开头，本局已用过的成语不会再出现
- 看图猜：小礼物或时间到了给提示（字数、首字、中间字），揭晓前不给完整答案；跳过会公布答案并结束这题，刷新会换一道新题

想恢复旧的「送礼物灌随机词」，把该档动作改成 **注入随机词**。

## 点赞进度条

全房间共用一条点赞进度，画在 Overlay 顶部。默认满 **100** 赞解锁一条提示，也可以改成满赞后开启限时 **2 倍积分**（时长、倍数、目标都能改）。超出的赞会留在下一轮进度里。

直连抖音时，房间里的点赞消息会推进这条进度。没开播时用控制台的「模拟点赞 +20」或「模拟点赞灌满」。

## 积分、连击、日榜和周榜

答对会记分。同一个人连续答对会叠加连击奖励（默认从第 2 连开始，每次多 15 分，最多加 60）。弹幕答题里，发了 A/B/C/D 或选项但答错，连击清零；语义猜词里没猜中不会断连击。成语接龙里，接不上的已知成语会断连击；看图猜里，发出像样的错误答案也会断连击。

段位按累计积分算。默认每 180 分升一小级，每大段 5 小级：青铜 5→1、白银、黄金、铂金、钻石、星耀、王者、挑战者。控制台「积分段位」可改。

积分、段位、连击记录和日榜周榜是**一个账号、六个玩法共用**。优先用抖音用户 ID，弹幕里没有 ID 时用昵称。切换玩法、开启新回合、重启服务都不会把分清掉。只有控制台里点 **清空积分榜** 并确认，才会删掉 `data/leaderboard.db` 里的积分和流水。

倒计时走完，或有人获胜之后，画面会先停几秒（默认 8 秒，可改成 5–10 秒）把答案和获胜者亮出来，然后**自动开下一局**。控制台「揭晓后自动开始下一局」默认开着，适合挂机直播。关掉之后，揭晓结束就停在空闲，要手动再开。点「跳过当前」也会停住，不会马上重开。成语接龙每一步超时会换一个新开头；这局实在接不下去时，同样会自动开一局新的。

揭晓这几秒里观众发的弹幕仍会出现在画面下方。勾上「揭晓期间的弹幕计入下一局」后，这些话会在下一局开始时当作猜测处理。

Overlay 底部有一条弹幕流，昵称加内容，礼物、点赞、进场颜色不同，几秒后淡出。人多的时候每秒最多留 8 条聊天或点赞，礼物和进场仍会留下。控制台模拟弹幕也会出现在这里，不管当前有没有在进行回合。

同一条弹幕还会从画面右侧飞到左侧，多行并排、同一行不重叠。它们飞在提示语和答案卡片之间的一条空带里，不压住倒计时、点赞条、答案和积分榜。礼物是金色，答对是绿色。控制台「飞过弹幕」可以开关、调节速度、字号、透明度、行数，以及人多时每秒最多飞几条。模拟弹幕一样会飞。底部那条聊天仍然保留。游戏画面如果还是只有底部聊天，刷新一次 /overlay。

控制台右上角有醒目的 **暂停 / 继续**。暂停后当前这一局的倒计时停住，到点不会揭晓，也不会自动开下一局。弹幕、礼物、点赞和进场仍显示在画面上，但这期间的猜测不计分，礼物也不会解锁提示或加时。点继续后从剩下的秒数接着走。刷新控制台或游戏画面，暂停状态还在。只有重启服务时，进行中的这一局会结束，但「暂停中」这个标记会留下来。

积分写在本机 SQLite（`data/leaderboard.db`）。Overlay 上的积分榜会在 **日榜 / 周榜 / 总榜** 之间轮换，竖屏只显示当前这一榜，避免三块榜叠在一起。日榜、周榜按北京时间的当天 0 点和本周一 0 点切分。升级时画面会再弹一次段位动画。

服务启动时会检查这份数据库。缺字段或缺表时才升级：只追加表和字段，不删除、不重建已有的表。升级前会先用 SQLite 备份接口复制一份到 `data/backups/leaderboard-年月日-时分秒-微秒.db`。已经升过的库再次启动不会再复制。原来 `scores` 里的积分会归入全局账号 `global_accounts`（同一个抖音用户 ID 只留一份，前后空格会并到一起），旧行仍然留在 `scores` 里。已经写进库里的额外成语和看图猜题目会抄进统一题库 `bank_items`，旧表不删。内置词表文件 `app/data/wordpool.txt`、`app/data/questions.json`、`app/data/idioms.txt`、`app/data/emoji_puzzles.json` 升级时不会改；控制台之后新增的题目写在这个数据库里，备份会一起带走。库里如果另有别的表，也会原样留下。

## 成语接龙

观众发四字成语，下一句的第一个字必须是上一句的最后一个字。控制台可以打开「允许同音不同字」，这时拼音相同（不看声调）也能接上，例如「意气风发」后面可以接「法不责众」。

词表在 `app/data/idioms.txt`，只认四个汉字的行。同一局用过的成语不能再接。每一步有倒计时（默认 30 秒），没人接上就换一个新开头，这局继续，不清积分。

不在词表里、但字能接上的四字词，如果配了 MiniMax 或对话接口，会在后台问模型是不是常见、健康的成语。模型点头后才入库加分；这期间如果已经换了开头，迟到的判定不算分。本地词表始终是准的，模型超时或失败就当没接上。

## 看图猜

画面上是一串表情，观众猜成语或歌名。控制台可以选择只出成语、只出歌名，或两样轮换。内置题目在 `app/data/emoji_puzzles.json`，答案按常见成语和歌名核对过，内容适合全年龄直播。

配好 MiniMax（或备用对话接口）后，控制台「题库」里选看图猜，可以按成语或歌名生成题目。默认先预览再入库，写入本机数据库。主播能在控制台看到答案并删除不合适的题。删除内置题只是本机隐藏，不会改仓库里的文件。

提示会随时间出现，礼物和点赞也能解锁。揭晓前最多给到字数、首字和中间的一个字。答案比对会去掉空格和标点，也会去掉「我觉得是」这类前缀。默认同音也可以算对，可在参数里关掉。

## 在控制台里试这三件事

1. 打开控制台，玩法选「语义猜词」，指定谜底可填「淘气」，点 **开启新回合**。
2. **礼物**：点「模拟小礼物」，画面应弹出感谢并出现提示；点「模拟大礼物」，倒计时应增加。把大礼物效果改成「刷新题目」或「跳过当前」再送一次，看词语是否更换或回合结束。
3. **点赞**：点「模拟点赞 +20」，顶部进度增加；点「模拟点赞灌满」，进度走满并触发提示或双倍积分（看「点赞进度条」里的奖励）。
4. **积分榜**：切到「弹幕答题」，连续用同一昵称答对两题，公告里会出现连击；Overlay 右侧或底部积分榜会轮换日榜、周榜、总榜。再切到「成语接龙」接上一句，同一昵称的积分会加上去，不会另开一份。
5. **进场**：点「模拟进场」，画面短暂显示欢迎语。直连自己的直播间后，真实的点赞、礼物和进场会走同一条逻辑。
6. **成语接龙**：玩法选「成语接龙」，指定开头可填「一心一意」，点开启新回合。模拟弹幕发「意气风发」应接上并加分；再发同一个词会提示用过。把大礼物改成「跳过当前」再送一次，会换一个新开头。
7. **看图猜**：玩法选「看图猜」，指定答案可填「马马虎虎」，点开启新回合。画面是表情，模拟弹幕发「马马虎虎」或带标点的同一句应猜中。题库卡片里能看到答案，不合适的点 × 删除。
