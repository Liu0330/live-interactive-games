# 直播互动玩法控制台

给抖音主播用的**本机互动玩法台**：开一个竖屏游戏画面，用「抖音直播伴侣」窗口采集推到直播间，观众发弹幕就能玩。

同一套壳里有 4 个玩法，控制台随时切换，不用重启：

1. **语义猜词**（主玩法，画面标题「挑战最强大脑」）
2. **弹幕答题**
3. **数字炸弹**
4. **弹幕抽奖**

本仓库是原创实现，不包含任何商业软件的安装包、卡密或破解。

---

## 环境要求

- Windows / macOS / Linux
- Python 3.11 或以上
- Google Chrome（或 Edge）用来打开控制台和游戏画面
- 可选：硅基流动 API Key，用来做更准的语义向量、AI 扩词库、语音播报

---

## 安装

在项目目录打开终端：

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

---

## 启动

```bash
python -m app
```

浏览器打开：

| 页面 | 地址 |
| --- | --- |
| 控制台（主播看，含谜底） | http://127.0.0.1:8000/control 或 http://127.0.0.1:8000/#/control |
| 游戏画面（给伴侣采集） | http://127.0.0.1:8000/overlay 或 http://127.0.0.1:8000/#/overlay |

控制台点「打开游戏界面」也会弹出 Overlay。

密钥、房间号、玩法参数会写到本机 `data/config.json`，**不要提交到 Git**。也可用环境变量：

```bash
# Windows PowerShell
$env:SILICONFLOW_API_KEY="sk-..."
$env:DOUYIN_ROOM_ID="你的房间号"

# macOS / Linux
export SILICONFLOW_API_KEY=sk-...
export DOUYIN_ROOM_ID=你的房间号
```

## 第一次开播流程（抖音直播伴侣）

1. 本机先 `python -m app`，确认控制台和 Overlay 都能打开。
2. 打开 **抖音直播伴侣**，登录你自己的账号。
3. 在伴侣里选 **添加窗口**（或「窗口采集」），选中 Chrome 里的 **游戏画面** 那个窗口。
4. 把采集区域裁成 **竖屏 9:16**。推荐画布 **1080 × 1920**。
5. 直播分类选 **其他游戏玩法**（按平台当前类目为准，不要乱选违规类目）。
6. 无人值守或不说话时，把麦克风静音，避免环境噪音。
7. 背景音乐可用汽水音乐等本机播放器，音量压低，不要盖过游戏提示音。
8. 控制台先用「模拟弹幕」走一遍：开启新回合 → 发几个词 → 看 Overlay 排名是否跳动。
9. 确认无误后再点「开始直播」。

Overlay 按 1080×1920 设计，窗口随便缩放都会等比适配。伴侣里把黑边裁掉即可。

## 硅基流动（可选，强烈建议语义玩法开播时配置）

1. 打开 https://cloud.siliconflow.cn 注册并创建 API Key。
2. 在控制台「AI 生成词库」里粘贴密钥，选一个当前列表里的模型（默认 `deepseek-ai/DeepSeek-V3`）。
3. 点 **保存密钥**，再点 **测试连接**。
4. 需要扩词库时填主题（如「食物」「四字成语」），点 **AI 生成并入库**。
5. 有密钥时，语义相似度走 `BAAI/bge-m3` 向量；没有密钥时自动用本地字面 + 相关词表，**离线模拟也能玩**。
6. 语音播报：有密钥时走 CosyVoice；否则 Overlay 用浏览器 `speechSynthesis`。

**不要**把密钥写进仓库，也不要发给别人。

## 观众怎么玩

观众在你的直播间发评论即可，无需安装任何东西。

| 玩法 | 怎么参与 | 怎么赢 |
| --- | --- | --- |
| 语义猜词 | 发一个词语 | 相似度达到阈值（默认 80%）或猜中谜底 |
| 弹幕答题 | 发 A/B/C/D 或完整答案 | 第一名正确得分 |
| 数字炸弹 | 发整数 | 猜中范围内的秘密数字（可改成「最后安全者赢」） |
| 弹幕抽奖 | 发口令（默认「抽奖」） | 倒计时结束滚动开奖，礼物可加权 |

控制台可以随时 **模拟弹幕 / 模拟礼物**，方便没开播时联调。

## 抖音房间直连（读你自己的直播间）

控制台填 `live.douyin.com/<房间号>` 后面的数字，点 **开始直连**。

程序会尝试用公开网页直播接口拉取你房间的弹幕和礼物，接到同一条评论总线。这是给你**自己的房间**用的，不要去连别人的房间做采集骚扰。

抖音网页协议经常改，直连失败时控制台会显示状态。此时：

1. 确认房间号正确、直播已经开出去；
2. 仍失败就用「模拟弹幕」或让场控在控制台代发；
3. 也可以自己写一个接入插件（见 `app/ingest/`），接到 `EventBus` 即可。

本程序**不会**用嵌入式浏览器去登录别人的账号，也没有卡密系统。

## 语义猜词说明

- 谜底来自 `app/data/wordpool.txt`，第一行固定为 `# 语义猜词 谜底词库`，后面一行一词。
- Overlay **不会提前显示谜底**。猜中或时间到才揭晓。
- 控制台实时状态类似：`当前回合正在 playing - 词语是 [ 巧夺天工 ]`。
- 默认礼物（可在 `data/config.json` 改）：
  - 小心心 → 随机 50 词
  - 大啤酒 → 随机 100 词
  - 鲜花 → 随机 300 词
  - 你最好看 → 额外提示
  - 点赞满 30 次 → 随机提示
- **禁止**往词库里加违规词、政治敏感、色情低俗内容。词库出事可能导致直播间被限流或 **10 分钟封禁**。

自带 200+ 条常见安全名词，可在控制台增删，或用 AI 按主题扩写。

## 积分与段位

默认每 180 分升一小级，每大段 5 小级：青铜 5→1、白银、黄金、铂金、钻石、星耀，再到王者 / 挑战者。控制台「积分段位」可改。积分存在本机 SQLite（`data/leaderboard.db`）。
